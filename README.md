### Description

هدف آزمون معماری های متفاوت ٫ پیاده سازی یادگیری نظارت نشده با انعطاف‌پذیری وابسته به زمان اسپایکی ٫ یادگیری نظارت شده با شبکه عمیق و آموزش شبکه با الگوریتم های غیر وابسته به گرادیان.
